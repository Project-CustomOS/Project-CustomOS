# Project-CustomOS

CustomOS is a custom operating system written in C.
In its current early stages (0.x.x versions), it is a command-line UEFI based operating system.
Updates will come every once in a while! Updates always take a bit of time of code and troubleshooting.
I (as a human) design all of the concepts, how it works, etc. for the OS.
We strive to provide a quality product. If you find any errors, bugs, or more in the OS, let us know!


CustomOS plans to become a fully graphical operating time by the 1.0 release. So stay tuned!
